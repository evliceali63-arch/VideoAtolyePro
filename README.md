# Video Atölye Pro

Android üzerinden geliştirilen kişisel video ve fotoğraf düzenleme uygulaması. İlk sürüm: temel arayüz ve fotoğraf/video seçme. Gelişmiş efektler ve otomatik montaj ileriki sürümlerde geliştirilecek.

GitHub Actions > Android APK > Run workflow ile debug APK derlenebilir. Bu depo geliştirme aşamasındadır.
